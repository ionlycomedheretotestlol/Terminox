# Bundled PRoot

`libproot*.so` are prebuilt, statically linked PRoot executables (renamed so Android
extracts them to the native library directory, where they are allowed to run).

- Binaries: https://github.com/green-green-avk/build-proot-android (packages/, MIT build scripts)
- PRoot source (GPL-2.0): https://github.com/green-green-avk/proot
- talloc (LGPL-3.0): https://talloc.samba.org
